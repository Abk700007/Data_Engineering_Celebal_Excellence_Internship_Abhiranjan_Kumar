# Power BI Dashboard

Save your completed Power BI dashboard file (e.g. `Food_Delivery_Analytics_Dashboard.pbix`) in this directory.

### Completed Pages:
1. **Executive Summary**: Geographic sales mapping, city comparison metrics, and corporate KPI counters.
2. **Restaurant Leaderboard**: Ranked performance index, cuisine-wise sales splits, and customer ratings.
3. **Daily Operations**: Time-series order volume and daily revenue trends.
4. **Order Drillthrough**: Raw transaction browser with granular filters for City, Status, and Restaurant name.
